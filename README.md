# 🎡 游戏分组大转盘

> 一个专为游戏组队设计的霓虹赛博风大转盘工具，支持智能名单导入、随机分组、积分排行榜等功能。

## ✨ 功能特性

### 🎯 幸运大转盘
- Canvas 绘制的精美转盘，霓虹发光外环 + 金色指针
- 丝滑缓入缓出转动动画，转动时指针自然抖动
- 停止时阻尼回弹，中奖扇区金色光晕高亮
- 彩带庆祝特效
- 抽中后自动从待抽列表移除，进入「已抽中」列表，支持单条/全部复原

### 👥 游戏分组
- **转盘分组模式**：逐个转盘抽取，依次分配到各组
- **快速随机分组**：一键打乱分配
- 支持 2-8 组，每组 1-10 人（适配英雄联盟竞技场 3v3v3v3 等模式）
- 组间人员拖拽调整
- 比赛名次录入 + 自动积分结算

### 🏆 积分排行榜
- 个人累计总积分榜（金银铜牌动效）
- 参赛次数、最佳名次统计
- 总玩家数、总场次、总积分、人均积分数据面板
- 自定义积分规则（第1-8名各多少分）

### 📜 抽奖历史
- 自动记录所有转盘抽奖和分组结果
- 支持关键词搜索（参与者、组名）
- 详情弹窗查看完整记录
- 单条删除、JSON 导出

### ⚙️ 设置面板
- 转盘转动时长调节（3-15秒）
- BGM 开关与音量调节
- 深/浅色主题切换
- 6 种转盘配色方案（霓虹赛博、落日余晖、深海幻境、马卡龙、宝石翡翠、极简灰度）
- 数据导出/导入/清空

### 🎵 BGM 音频
- 转盘转动时自动播放背景音乐，停止时淡出
- 支持本地音频文件（`bgm.mp3`）

## 📖 使用说明

### 批量导入名单

在转盘页面的「批量导入」文本框中粘贴名单，支持以下格式：

**每行一个名字：**
```
张三
李四
王五
```

**逗号/顿号/空格分隔：**
```
张三, 李四, 王五
张三、李四、王五
张三 李四 王五
```

**智能解析游戏房间ID格式（自动提取名字，去除#号及后缀）：**
```
大宝 #5269 進入組隊房間
小明 #1234 進入組隊房間
小红 #5678
```

导入后自动去重，已抽中的名字会自动复原。

### 转盘抽奖

1. 导入或手动添加选项
2. 点击「开始转动」
3. 转盘停止后显示中奖者，自动移入「已抽中」列表
4. 需要重抽时，在「已抽中」列表点击复原按钮

### 游戏分组

1. 切换到「分组」页面
2. 选择分组模式（转盘分组/快速随机）
3. 设置分组数量和每组人数
4. 点击开始分组
5. 分组完成后，输入各组名次
6. 点击「确认结算」，排行榜自动更新

### 数据存储

所有数据（选项、已抽中、历史记录、排行榜、设置）保存在浏览器本地（localStorage），刷新页面不丢失。建议定期在「设置」页面导出数据备份。

## 📦 部署到 GitHub Pages

1. 在 GitHub 创建新仓库（Public）
2. 上传 `index.html` 和 `bgm.mp3` 到仓库根目录
3. 进入 **Settings → Pages**
4. Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`
5. 保存后等待 1-2 分钟，即可通过 `https://你的用户名.github.io/仓库名/` 访问

> **注意**：文件必须放在仓库根目录，不要放在子文件夹中。

## 🛠️ 技术栈

- **HTML5** — 页面结构
- **CSS3** — 样式与动画（霓虹赛博风、毛玻璃、发光效果）
- **JavaScript (ES6+)** — 业务逻辑
- **React 18** — UI 框架（CDN 引入）
- **Babel Standalone** — JSX 编译（CDN 引入）
- **Canvas API** — 转盘绘制
- **Web Audio API** — 音频播放与淡出
- **localStorage** — 数据持久化

**无构建工具、无后端依赖、纯静态单文件应用。**
